# 豆瓣书影音导入助手

一个思源笔记插件：在插件内置浏览器里打开豆瓣详情页，一键提取书籍、电影、电视剧／动画、音乐信息，写入思源属性视图数据库，并自动生成一篇感想笔记。

![预览](preview.png)

## 功能特性

- **内嵌豆瓣浏览器**：插件内直接打开豆瓣，无需切换到外部浏览器。
- **四类媒体**：支持书籍、电影、电视剧／动画、音乐。
- **一键提取**：在详情页点击「从当前页面提取」，自动抓取标题、评分、简介、作者／导演／演员等信息。
- **可编辑预览**：提取结果可先逐字段修改，确认无误后再导入。
- **写入数据库**：按媒体类型写入对应的属性视图数据库，字段格式与思源原生数据库一致。
- **封面本地保存**：封面经思源后端代理下载（绕过豆瓣防盗链），保存到本地 `assets`，不再依赖远程链接。
- **感想笔记模板**：同时新建一篇感想笔记，结构与「感想笔记」模板一致，含豆瓣评分、我的评分、简介、优点、缺点、感想等段落。
- **灵活配置**：笔记本、数据库、笔记存放位置均可在设置中用下拉框选择或修改。

## 使用方法

1. 点击顶栏的插件图标，打开面板。
2. 选择媒体类型（书籍／电影／电视剧／动画／音乐）。
3. 点击「打开豆瓣」，在内置浏览器中打开对应详情页。
   - 如果在搜索页遇到「搜索访问太频繁」提示，请先在外部浏览器打开详情页，再把详情页地址复制到插件地址栏点击「前往」。详情页限制比搜索页宽松。
4. 到详情页后点击「从当前页面提取」。
5. 在下方预览区核对/修改字段，点击「导入思源」。

导入完成后会：
- 在所选笔记本的指定路径下新建感想笔记；
- 把该笔记作为一行写入对应的属性视图数据库；
- 把封面保存到本地 assets。

## 设置说明

点击面板右上角的「设置」展开配置：

| 项目 | 说明 |
| --- | --- |
| 数据库所在笔记本 | 数据库所在的笔记本；切换后下方数据库列表会同步过滤为该笔记本内的数据库，并清空不适用的旧选择 |
| 封面目录 | 封面图片保存目录，默认 `assets/媒体封面` |
| 各类媒体 | 选择该类型对应的数据库（下拉框显示「名称（路径）」）；「感想笔记位置」是该类型笔记在笔记本内的父路径，例如 `/豆瓣电影`；选中数据库时会自动按数据库路径填好 |

修改后点击「保存设置」。

## 安装

在思源「设置 → 集市 → 插件」中搜索「豆瓣书影音导入助手」并安装；或手动下载 Release 里的 `package.zip`，解压到 `{工作空间}/data/plugins/siyuan-media-importer/` 后重启思源。

## 注意事项

- 需要思源桌面端（使用内嵌浏览器与后端代理能力）。
- 封面下载依赖思源后端代理，因此封面能正常保存，即使内置浏览器里豆瓣图片因防盗链显示为裂图也不影响导入。
- 首次使用需在设置里确认笔记本与四类数据库；数据库需先在思源中打开过，才能出现在下拉列表里。
- 数据源自豆瓣公开页面，请遵守豆瓣的使用条款，不要高频批量抓取。
