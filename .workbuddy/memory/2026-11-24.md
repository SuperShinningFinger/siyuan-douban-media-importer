## 【真正根因】forwardProxy 参数格式用错，封面一直下载失败
- 用户给参考项目 douban-api-rs（只返回豆瓣 CDN 图片 URL，不做下载），提示后查思源内核源码 `kernel/api/network.go` + `kernel/apicontract/network.go` 找到根因。
- **`/api/network/forwardProxy` 的 headers 格式是 `[{Header名: 值}]` 对象数组**（契约 `[]map[string]JSONValue`），内核用 `for key, value := range pair` 遍历。旧插件 getImg.ts 用的 `[{name:"...",value:"..."}]` 是**错的**——内核会把 `name`/`value` 当 header 名，真正要的 `Referer` 根本没发出去，豆瓣照样 418。
- 正确写法：`headers: [{ "User-Agent": "..." }, { Referer: "https://book.douban.com/" }]`，`payload: ""`，`payloadEncoding: "text"`，`responseEncoding: "base64"`。
- **返回结构** `NetworkForwardData`：`{url, status, contentType, body, bodyEncoding, headers, elapsed}`。`contentType` 是顶层字符串（小写 t），body 是 base64。fetchSyncPost 返回 `{code,data}`，取 `resp.data`。
- 之前读 `data.headers["Content-Type"][0]` 不稳（键大小写不固定），改为优先 `data.contentType`，再兜底遍历 headers 找 content-type。
- 已按契约修正 `fetchImageAsDataUrl`，tsc + build + 安装通过。需重载插件重测。
